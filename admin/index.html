Paste your GitHub access token. It stays in this browser only and is used to save your edits back to GitHub. Nothing is stored on the site.

First time? How to get your token (2 minutes)
  1. Open github.com → new fine-grained token (sign in if asked).
  2. Token name: anything, e.g. "517 site editor".
  3. Resource owner: your account (Turnstyle19320).
  4. Repository access: choose Only select repositories → pick 517edtech-site.
  5. Permissions: expand Repository permissions → set Contents to Read and write.
  6. Click Generate token, copy it, and paste it above. (You only do this once per browser.)

Lost it or leaving the team? Just delete the token on GitHub — it only ever had access to this one repo.
